# 💊 Pharmacy Management System

A **Java-based Pharmacy Management System** developed as part of the **OOP1 course project**.  
This application helps manage medicines, customers, and sales efficiently using **Object-Oriented Programming (OOP)** principles.

---

## 🧩 Features

- 🏪 **Medicine Management** – Add, update, delete, and search medicines.  
- 👥 **Customer Management** – Store and manage customer details.  
- 🧾 **Billing System** – Generate and print invoices for customers.  
- 📦 **Stock Tracking** – Monitor available stock and alert when medicines run low.  
- 🔐 **User Login System** – Admin and employee authentication for secure access.  
- 💽 **Data Storage** – Uses file handling or database (optional) for saving records.

---

## 🧠 OOP Concepts Used

- **Class & Object** – Each module (Medicine, Customer, Sale) represented by a class.  
- **Encapsulation** – Data hiding and getter/setter methods.  
- **Inheritance** – Common features shared across user types.  
- **Polymorphism** – Method overloading and overriding for flexibility.  
- **Abstraction** – Simplified interfaces for managing system complexity.
